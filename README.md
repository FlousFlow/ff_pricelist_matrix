# Flous Flow — Odoo 19 Modules / موديولات Flous Flow لأودو 19

Official Flous Flow add-ons for Odoo 19 Community.
موديولات Flous Flow الرسمية لأودو 19 Community — بدعم كامل للعربية (RTL).

## Modules / الموديولات

| Module | Description |
|---|---|
| `ff_pricelist_matrix` | Price Matrix — manage Pricelist × Product Category discounts from one standard editable list, with an Excel import wizard and a full audit trail. Built on the standard Odoo pricing engine. / **مصفوفة أسعار الفئات** — إدارة خصومات (قائمة الأسعار × فئة المنتج) من قائمة قياسية واحدة مع معالج استيراد Excel وسجل تدقيق كامل — فوق محرك التسعير القياسي. |

## Installation / التثبيت

Clone this repository and add its path to your `addons_path`, then install
the module from the Apps menu.

```bash
git clone https://github.com/FlousFlow/ff_pricelist_matrix.git -b 19.0
```

استنسخ الريبو وأضف مساره إلى `addons_path` ثم ثبّت الموديول من قائمة التطبيقات.
