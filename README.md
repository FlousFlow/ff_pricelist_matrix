# Flous Flow — Odoo 19 Modules

Official Flous Flow add-ons for Odoo 19 Community.

## Modules

| Module | Description |
|---|---|
| `ff_pricelist_matrix` | Price Matrix — manage Pricelist × Product Category discounts from one standard editable list, with an Excel import wizard and a full audit trail. Built on the standard Odoo pricing engine. |

## Installation

Clone this repository and add its path to your `addons_path`, then install
the module from the Apps menu.

```bash
git clone https://github.com/FlousFlow/ff_pricelist_matrix.git -b 19.0
```
