Price Matrix — Category Discounts Manager

Manage Pricelist × Product Category → Discount % from one standard Odoo list. Every row is a real product.pricelist.item rule (Apply on: Product Category, Compute Price: Discount, Based on: Sales Price) — so Sale Orders, POS, Website and every consumer of the standard Odoo pricing engine keep working untouched. No parallel pricing engine, no custom front-end: 100% standard views.

Highlights

  • Standard editable list — one row per (Pricelist × Category), edit the discount inline; native search, grouping, dark mode and RTL.
  • Smart defaults — new rows are preset to category / percentage / sales price; you only pick the pricelist, the category and the %.
  • Ownership & safety — the module only touches rules it created (managed_by_matrix); manual pricelist rules are never modified or deleted.
  • Deterministic priority — deeper category wins over parents, product exceptions win over categories, quantity breaks keep working: standard Odoo rule order, enforced and documented.
  • One rule per cell — duplicate managed rules for the same pricelist/category are blocked at DB level.
  • Excel import wizard — upload, auto-detect columns (Barcode → Internal Reference matching, never by name), reverse-engineer per-category discounts, rounding-tolerance normalization (14.999999 → 15), preview with consistent/inconsistent categories before applying.
  • Audit trail — old/new discount, pricelist, category, user and date for every managed change.
  • Multi-company — only pricelists of your active companies are visible and editable.
  • Security groups — Price Matrix User (read) / Price Matrix Administrator (edit, import, history).
  • Uninstall-safe — managed rules survive as ordinary percentage rules; nothing is deleted behind your back.

Why the behavior is deterministic

Standard Odoo picks the first applicable rule in the order applied_on, min_quantity desc, categ_id desc, id desc: variant → product → category → global, higher min_quantity first, and — because a child category id is always greater than its parent's — the deepest category always wins. The module forbids duplicates inside the managed scope, so the last tie-break can never surprise you.

Excel import flow

  1. Upload the workbook (.xlsx — openpyxl required on the server).
  2. Analyze: columns auto-detected (Barcode / Internal Reference / Category / Base Price; every other column = a pricelist matched by name).
  3. Discounts reverse-engineered per category: (Base − Price) / Base, normalized within the rounding tolerance.
  4. Preview: sample counts, min/max, consistent ✔ / inconsistent ⚠ per (category × pricelist). Inconsistent ones default to Skip — never guessed.
  5. Apply writes through the same audited, constraint-checked path.

Installation

  • Requires Odoo 19 Community, sale_management and openpyxl.
  • On install the "Pricelists" feature (Odoo 19 setting) is enabled for existing internal users automatically.
  • Start at Sales ▸ Configuration ▸ Price Category Matrix.
